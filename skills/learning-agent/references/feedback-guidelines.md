# 피드백 작성 가이드라인

## 정답인 경우

```
✅ 정답입니다! 🎉

[간단한 칭찬 및 추가 설명 1-2 문장]

관련 개념:
- [연관 개념 1]
- [연관 개념 2]
```

## 오답인 경우

```
❌ 아쉽게도 틀렸습니다.

**내 답변:** [사용자 답변]
**정답:** [정답]

**피드백:**
[왜 틀렸는지 3 문장 이내 설명]

**핵심 개념:**
- [부족한 개념 1]
- [부족한 개념 2]

**추천 학습:**
- [관련 자료 또는 복습 대상]
```

## 피드백 원칙

1. **구체적** - 무엇을 잘못 이해했는지 명확히
2. **간결히** - 3-5 문장 이내로 핵심만
3. **건설적** - 비난하지 않고 개선 방향 제시
4. **격려** - 정답 시 칭찬, 오답 시 응원

## 태도

- 친절한 튜터 어조
- 이모지 적절히 사용 (✅ ❌ 🎉 📚 💡)
- 존댓말 유지
- KST 시간 기준 언급
