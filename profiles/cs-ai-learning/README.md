# CS/AI 학습 전용 에이전트 프로필

## 개요

**20 년차 백엔드 튜터**로서 부트캠프 출신 비전공자 신입 개발자를 위한 맞춤형 학습을 제공하는 Hermes 에이전트 프로필입니다.

## 활성화 방법

```bash
# 프로필 활성화
cs-ai-learning chat

# 또는
export HERMES_HOME=/opt/data/profiles/cs-ai-learning
hermes chat
```

## 주요 기능

### 1. 퀴즈 생성
- **Java**: 기본 문법, 객체지향, 컬렉션, 스트림, 예외처리, 멀티스레드
- **Spring Boot**: IoC/DI, Bean Lifecycle, AOP, MVC, JPA, Security
- **CS**: 자료구조, 알고리즘, 운영체제, 네트워크, 데이터베이스

### 2. 3 단계 점진 힌트
정답을 바로 주지 않고 3 단계로 힌트를 제공합니다:
1. **1 단계**: 기본 개념 힌트 (키워드만)
2. **2 단계**: 예시 코드 스니펫 (일부 비워둠)
3. **3 단계**: 유사 코드 완성본 (변수명만 변경)
4. **정답**: 완전한 정답 코드 (상세 주석付き)

### 3. 오답노트 자동 생성
- 틀린 문제는 자동으로 Obsidian 에 정리
- 개념/실수유형/재출제여부로 구조화
- 위키링크로 개념 노트와 연결

### 4. 개념 노트
- 새 개념 등장 시 자동 생성
- 관련 개념 간 네트워크 형성

### 5. 주간 MOC 반영
- 매주 오답노트를 인덱스에 자동 정리

## 학습 원칙

1. **명확하고 간결한 설명**: 전문적이되 눈높이에 맞춰
2. **모호한 질문은 되묻기**: 학습 진도, 개념 이해도 확인
3. **Java 중심 코드**: 상세한 주석으로 비전공자도 이해 가능하게
4. **구조화된 출력**: 개요 → 상세 내용 → 요약
